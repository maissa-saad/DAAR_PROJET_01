Première étape : Définir le langage regEx
    - Premier INPUT : chaine de caractère contenant le regex 
    - Premier OUTPUT : la regex prête à l'utilisation









Utilisation :

Sur terminal taper : python main.py regex fichier.txt
    - regex : la chaine de caractère contenant la regex, exemple de regex : "(a|b)*"
    - fichier.txt : le nom du fichier dans lequel on va chercher les mots correspondant à la regex
Avec Makefile taper : make main.py regex fichier.txt (on verra peut etre qu'on le modifiera par la suite)
